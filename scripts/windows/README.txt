Driftwave: internet radio.

To install it, right-click Install.ps1 and choose "Run with PowerShell". It installs for you alone (no admin rights
needed) into %LOCALAPPDATA%\Programs\Driftwave, with a Start menu shortcut and an entry in Settings > Apps.

Driftwave updates itself: Settings > Updates.

To run it without installing, open Driftwave.exe from this folder (notifications need the installed copy).
